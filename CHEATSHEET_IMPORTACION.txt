  1. VALIDAR
     ./validador_csv.py archivo.csv

  2. SUBIR
     ./subir_csv.sh archivo.csv CODIGO

  3. IMPORTAR (con persistencia SSH)
     ./importar_con_tmux.sh

  4. DESCONECTAR (sigue corriendo)
     Ctrl+b d

│ Ver logs en vivo        │ tail -f logs/importacion_*.log           │
│ Verificar duplicados    │ ./verificar_duplicados.sh                │
│ Ver procesados          │ ls -lht procesados/                      │
│ Detener importación     │ ./importar_con_tmux.sh --kill            │
└─────────────────────────┴──────────────────────────────────────────┘

  Ctrl+b [       Modo scroll/ver historial
  q              Salir del modo scroll
  Ctrl+b ?       Mostrar todos los atajos

EJEMPLO 1: Importar Medicina

  ./subir_csv.sh MED.csv MED
  ./importar_con_tmux.sh

EJEMPLO 2: Importar Veterinaria desde Descargas
────────────────────────────────────────────────
  ./validador_csv.py ~/Descargas/veterinaria.csv
  ./subir_csv.sh ~/Descargas/veterinaria.csv VET
  ./importar_con_tmux.sh
  # Desconectar: Ctrl+b d

EJEMPLO 3: Modo Vigilancia (Múltiples Archivos)
────────────────────────────────────────────────
  ./importar_con_tmux.sh --watch
  # Desconectar: Ctrl+b d
  # Luego subir archivos:
  ./subir_csv.sh MED.csv MED
  ./subir_csv.sh VET.csv VET
  # Se procesarán automáticamente

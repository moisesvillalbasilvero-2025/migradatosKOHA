¡Ya no perderás el trabajo si te desconectas de SSH!


┌──────────────────────────────────────────────────────────────────────┐
│  🎯 IMPORTAR UN ARCHIVO CSV (FORMA SEGURA - RECOMENDADA)             │
└──────────────────────────────────────────────────────────────────────┘

  1️⃣  Validar el archivo (opcional pero recomendado)
      ./validador_csv.py MED.csv

  2️⃣  Subir el archivo
      ./subir_csv.sh MED.csv MED

  3️⃣  IMPORTAR CON PERSISTENCIA ⭐
      ./importar_con_tmux.sh

  4️⃣  Desconectarse de tmux (sin detener la importación)
      Presiona:  Ctrl+b  luego  d

      ¡IMPORTANTE! La importación continúa en segundo plano
      Puedes cerrar SSH sin problemas

  5️⃣  Reconectar cuando quieras ver el progreso
      ./importar_con_tmux.sh --attach


┌──────────────────────────────────────────────────────────────────────┐
│  📊 VER PROGRESO EN TIEMPO REAL                                      │
└──────────────────────────────────────────────────────────────────────┘

  En otra terminal SSH:
  ./monitor_importacion.sh --watch

  Muestra:
  ✓ Sesiones activas
  ✓ Procesos en curso
  ✓ Estadísticas de Koha
  ✓ Uso de recursos
  ✓ Últimos logs


┌──────────────────────────────────────────────────────────────────────┐
│  🔄 MODO VIGILANCIA AUTOMÁTICA (para múltiples archivos)             │
└──────────────────────────────────────────────────────────────────────┘

  1️⃣  Iniciar vigilancia en tmux
      ./importar_con_tmux.sh --watch

  2️⃣  Desconectarse (Ctrl+b d)

  3️⃣  Colocar archivos CSV en importar_aqui/
      Se procesarán automáticamente

  4️⃣  Reconectar para ver progreso
      ./importar_con_tmux.sh --attach


┌──────────────────────────────────────────────────────────────────────┐
│  🛠️  COMANDOS TMUX ESENCIALES                                        │
└──────────────────────────────────────────────────────────────────────┘

  DENTRO de sesión tmux:
    Ctrl+b d          Desconectar (sigue corriendo) ⭐
    Ctrl+b [          Modo scroll/ver historial
    q                 Salir del modo scroll

  FUERA de sesión tmux:
    ./importar_con_tmux.sh --attach    Reconectar
    ./importar_con_tmux.sh --status    Ver sesiones activas
    ./importar_con_tmux.sh --kill      Detener importación


┌──────────────────────────────────────────────────────────────────────┐
│  ✅ VALIDAR ARCHIVOS CSV ANTES DE IMPORTAR                           │

    ./validador_csv.py --dir importar_aqui/

  Modo estricto:
    ./validador_csv.py --strict archivo.csv

MODO 1: IMPORTACIÓN MANUAL CON TMUX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Comando: ./importar_tmux.sh importar_aqui/ARCHIVO.csv

Características:
✓ Se ejecuta en sesión tmux independiente
✓ Persiste aunque cierres SSH
✓ Puedes reconectar cuando quieras
✓ Logs automáticos
✓ Control total del proceso

Cuándo usarlo:
• Importaciones bajo demanda
• Cuando quieres control manual
• Para testing de archivos específicos

MODO 2: VIGILANTE PERMANENTE (AUTOMÁTICO) ⭐ RECOMENDADO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Comando: ./vigilante_permanente.sh start

Características:
✓ Monitoreo continuo 24/7
✓ Detecta archivos automáticamente (instantáneo con inotify)
✓ Los importa sin intervención humana
✓ Se ejecuta en tmux (persiste desconexiones)
✓ Control de carga del sistema
✓ Reintentos automáticos

Cuándo usarlo:
• Sistemas automatizados
• Importaciones nocturnas
• Integraciones con otros sistemas
• Cuando quieres "set and forget"

Cómo funciona:
1. Inicias el vigilante UNA VEZ: ./vigilante_permanente.sh start
2. Copias archivos a importar_aqui/: cp *.csv importar_aqui/
3. ¡Se importan automáticamente!
4. El vigilante sigue trabajando incluso si te desconectas

VIGILANTE PERMANENTE (AUTOMÁTICO):
-----------------------------------
./vigilante_permanente.sh start      # Iniciar (se queda vigilando 24/7)
./vigilante_permanente.sh status     # Ver qué está haciendo
./vigilante_permanente.sh logs       # Ver actividad en tiempo real
./vigilante_permanente.sh stop       # Detener
./vigilante_permanente.sh attach     # Ver sesión en vivo

IMPORTACIÓN MANUAL CON TMUX:
-----------------------------
./importar_tmux.sh ARCHIVO.csv       # Importar un archivo
./importar_tmux.sh --all             # Importar todos los pendientes
./importar_tmux.sh --status          # Ver sesiones activas
./monitor_tmux.sh                    # Dashboard en tiempo real
tmux attach -t NOMBRE_SESION         # Conectar a sesión

EJEMPLO PRÁCTICO: VIGILANTE PERMANENTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 1. Inicias el vigilante UNA SOLA VEZ (al principio)
./vigilante_permanente.sh start

# Salida:
✓ Vigilante iniciado exitosamente
  Sesión tmux:  koha-vigilante-permanente
  Log:          logs/vigilante/vigilante.log
  
  El vigilante procesará automáticamente cualquier archivo CSV
  que se copie en: importar_aqui/

# 2. Ahora simplemente copias archivos cuando quieras
cp /origen/BIBLIOTECA1.csv importar_aqui/
# ¡El vigilante lo detecta y lo importa automáticamente!

cp /origen/BIBLIOTECA2.csv importar_aqui/
# ¡También lo importa!

# Puedes copiar muchos a la vez
cp /origen/*.csv importar_aqui/
# Los procesa todos en orden

# 3. Puedes desconectarte de SSH
exit
# ¡El vigilante SIGUE trabajando!

# 4. Horas/días después, reconectas y ves qué ha hecho
ssh usuario@servidor
./vigilante_permanente.sh status

# Salida:
✓ Vigilante ACTIVO
  archivos_procesados = 15
  archivos_error      = 0
  ultimo_archivo      = BIBLIOTECA2.csv
  Importaciones activas: 1

Para máxima automatización y cero intervención:

1. Inicia el vigilante permanente:
   ./vigilante_permanente.sh start

2. Configúralo para inicio automático al arrancar el servidor (opcional):
   # Ver sección "Inicio Automático" en GUIA_VIGILANTE_PERMANENTE.md

3. Desde ahora, solo copia archivos:
   cp *.csv importar_aqui/

4. ¡El sistema hace el resto automáticamente!


Para control manual con persistencia:

1. Importa cuando quieras:
   ./importar_tmux.sh ARCHIVO.csv

2. Puedes desconectar:
   Ctrl+B luego D

3. Reconecta cuando quieras:
   tmux attach


Para administración completa:

1. Usa el gestor:
   ./gestionar_importaciones.sh

2. Elige opciones del menú

════════════════════════════════════════════════════════════════════════════
  🔄 FLUJOS DE TRABAJO
════════════════════════════════════════════════════════════════════════════

FLUJO 1: Importación Simple (Archivo pequeño/mediano)
───────────────────────────────────────────────────────
1. Validar:  ./validar_antes_importar.sh importar_aqui/ING.csv
2. Revisar:  Score > 70 y sin duplicados críticos
3. Importar: ./importar_biblioteca.sh ING
4. Verificar: firefox http://opac.una.edu.py/

FLUJO 2: Importación por Lotes (Archivo grande)
────────────────────────────────────────────────
1. Validar:  ./validar_antes_importar.sh importar_aqui/GRANDE.csv
2. Revisar:  Corregir errores si hay
3. Importar: ./importar_por_lotes.sh importar_aqui/GRANDE.csv 500
4. Monitorear: tail -f logs/batch_import_*.log
5. Ver reporte: firefox reportes/batch_import_*.html

FLUJO 3: Verificación Manual de Duplicados
───────────────────────────────────────────
1. Cargar funciones: source prevenir_duplicados.sh
2. Verificar CSV: verificar_duplicados_en_csv archivo.csv
3. Verificar BD: verificar_duplicados_csv_vs_bd archivo.csv
4. Interpretar código de retorno:
   → 0 = Sin duplicados (OK)
   → 1 = Barcodes duplicados (ERROR)
   → 2 = ISBNs/Títulos duplicados (ADVERTENCIA)

📋 CAMPOS REQUERIDOS PARA IMPORTACIÓN
═══════════════════════════════════════════════════════════════════════════

OBLIGATORIOS (sin estos, falla la importación):
✓ titulo           - Título principal
✓ codbiblio        - Código de biblioteca (POL, ARQ, FACEN, etc.)
✓ nroacceso        - Código de barras/acceso
✓ tipomaterial     - Tipo de material (LIBRO, REVISTA, TESIS, etc.)

CRÍTICOS PARA OPAC (sin estos, el catálogo luce pobre):
⭐ autor            - Autor principal (POL: 83.73% ✓)
⭐ temas_descrip    - Materias/keywords (POL: 91.95% ✓)
⭐ isbn_issn        - ISBN o ISSN (POL: 54.81% - mejorar)
⭐ editorial        - Editorial (POL: 99.31% ✓)
⭐ publicacion      - Año de publicación (POL: 99.58% ✓)
⭐ idioma_descrip   - Idioma (POL: 0% - CRÍTICO)
⭐ ubicacion        - Signatura topográfica (POL: 100% ✓)
⭐ sintesis         - Resumen/abstract (POL: 0.62% - mejorar)

RECOMENDADOS:
- edicion, volumen, ejemplar, nom_pais, procedencia, notas

Ver GUIA_PRESENTACION_JEFES.md sección 4 para métodos de obtención de datos.

═══════════════════════════════════════════════════════════════════════════
🔍 SISTEMA DE PREVENCIÓN DE DUPLICADOS
═══════════════════════════════════════════════════════════════════════════

El sistema detecta duplicados por:
✓ Código de barras (confianza 100%)
✓ ISBN/ISSN (confianza 95%)
✓ Título + Autor (confianza 70-90%)

Resolución automática:
- SKIP: Salta el duplicado
- UPDATE: Actualiza existente (RECOMENDADO)
- MERGE: Fusiona datos
- CREATE_NEW: Crea nuevo con código único

Pre-procesamiento CSV:
- Renumera códigos duplicados automáticamente
- Elimina duplicados exactos
- Genera códigos faltantes

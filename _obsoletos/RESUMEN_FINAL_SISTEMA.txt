✨ CARACTERÍSTICAS IMPLEMENTADAS

🤖 DETECCIÓN AUTOMÁTICA DE BIBLIOTECA
   - Extrae código del nombre del archivo
   - Ejemplos: BC.csv→BC, BCT.csv→BCT, FACEN.csv→FACEN
   - No requiere configuración manual

🛡️ CONTROL DE DUPLICADOS (2 NIVELES)

   Nivel 1: Dentro del CSV
   • Detecta códigos de acceso repetidos
   • Corrige automáticamente si > 50 duplicados
   • Genera archivo *_corregido.csv

   Nivel 2: Base de datos Koha
   • Consulta items existentes: SELECT COUNT(*) FROM items WHERE homebranch='XXX'
   • Informa cantidad y solicita confirmación
   • NO duplica registros en la importación
   • Solo agrega registros nuevos

🔍 FILTRADO POR BIBLIOTECA
   - Procesar solo biblioteca específica: --biblioteca CODIGO
   - Útil cuando tienes múltiples CSVs mezclados

📊 LOGS Y REPORTES DETALLADOS
   - Log completo: logs/importacion_CODIGO_FECHA.log
   - Reporte ejecutivo: logs/reporte_CODIGO_FECHA.txt
   - Trazabilidad 100% del proceso

⚡ MODO VIGILANCIA CONTINUA
   - ./importar_automatico.sh --watch
   - Monitorea carpeta cada 10 segundos
   - Procesamiento automático sin supervisión

📁 GESTIÓN AUTOMÁTICA DE ARCHIVOS
   - Exitosos → procesados/CODIGO_OK_FECHA.csv
   - Con errores → errores/CODIGO_ERROR_FECHA.csv
   - Sin pérdida de datos

   - Valida sintaxis XML generado
   - Verifica importación exitosa

💡 CÓMO FUNCIONA EL CONTROL DE DUPLICADOS
═══════════════════════════════════════════════════════════════════════

ESCENARIO: Biblioteca BC ya tiene 100 items en Koha.
           Quieres importar CSV con 500 registros nuevos.

PASO A PASO:

1. Sistema detecta "BC" del nombre archivo: BC.csv

2. Consulta Koha:
   SELECT COUNT(*) FROM items WHERE homebranch='BC'
   Resultado: 100 items

3. Informa al usuario:
   ⚠ Ya existen 100 items de esta biblioteca
   Se agregarán NUEVOS registros (no se duplicarán existentes)
   ¿Desea continuar? (SI/no):

4. Si usuario responde SI:
   • Los 500 nuevos se importan
   • Total después: 600 items
   • Los 100 anteriores NO se duplican

5. Koha maneja unicidad por:
   • Código de barras (barcode) único
   • biblionumber autogenerado

RESULTADO: Sin duplicados, solo agregados nuevos.

⚠️ SOLUCIÓN DE PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════

PROBLEMA: "Permission denied" al subir archivo
SOLUCIÓN:
  sudo chown mvillalba:mvillalba importar_aqui/
  sudo chmod 775 importar_aqui/

PROBLEMA: "No se detectó código de biblioteca"
SOLUCIÓN:
  Renombrar archivo para incluir código (3-6 letras)
  Ejemplo: mv datos.csv BC.csv

PROBLEMA: "La biblioteca 'XXX' NO existe en Koha"
SOLUCIÓN:
  Crear en Staff Interface:
  Administración → Bibliotecas → Nueva Biblioteca

PROBLEMA: "Formato CSV inválido"
SOLUCIÓN:
  Verificar campos obligatorios: titulo, nroacceso
  head -1 archivo.csv

PROBLEMA: "Error generando MARCXML"
SOLUCIÓN:
  Revisar log: cat logs/importacion_*.log
  Verificar encoding: file archivo.csv
  Debe ser UTF-8

PROBLEMA: Importación muy lenta
SOLUCIÓN:
  Normal para archivos grandes (>10MB)
  Esperar o dividir archivo en partes más pequeñas

🎓 CASOS DE USO REALES
═══════════════════════════════════════════════════════════════════════

CASO 1: Primera importación de una biblioteca
───────────────────────────────────────────────

1. Crear biblioteca en Koha (si no existe)
   Staff → Administración → Bibliotecas → Código: BC

2. Subir archivo
   ./subir_csv.sh bc_inicial.csv BC

3. Procesar
   ./importar_automatico.sh

4. Verificar
   ./importar_automatico.sh --stats


CASO 2: Agregar más registros a biblioteca existente
──────────────────────────────────────────────────────

1. Preparar CSV con solo registros NUEVOS

2. Subir
   cp bc_adicionales.csv importar_aqui/BC_nuevos.csv

3. Procesar
   ./importar_automatico.sh

4. El sistema:
   - Detecta 100 items existentes
   - Pregunta si continuar
   - Agrega solo los nuevos (NO duplica los 100)


CASO 3: Importar múltiples bibliotecas simultáneamente
───────────────────────────────────────────────────────

1. Colocar todos los CSV:
   cp bc.csv importar_aqui/BC.csv
   cp bct.csv importar_aqui/BCT.csv
   cp facen.csv importar_aqui/FACEN.csv

2. Procesar todas
   ./importar_automatico.sh

3. El sistema procesa cada una secuencialmente
   con validaciones individuales


CASO 4: Procesamiento automático continuo
──────────────────────────────────────────

1. Activar vigilancia (al inicio del día)
   nohup ./importar_automatico.sh --watch > vigilancia.log 2>&1 &

2. Durante el día, subir archivos cuando estén listos
   cp nuevo.csv importar_aqui/CODIGO.csv

3. Se procesan automáticamente cada 10 segundos

4. Al final del día, detener
   pkill -f importar_automatico.sh

🎯 BEST PRACTICES (Mejores Prácticas)
═══════════════════════════════════════════════════════════════════════

✅ ANTES DE IMPORTAR:
   • Verificar biblioteca existe en Koha
   • Revisar CSV tiene: titulo, nroacceso
   • Nombrar archivo con código claro: BC.csv, not biblioteca1.csv
   • Hacer backup del CSV original

✅ DURANTE LA IMPORTACIÓN:
   • No interrumpir proceso (esperar mensaje final)
   • Monitorear logs si archivo es grande
   • Responder confirmaciones cuando se soliciten

✅ DESPUÉS DE IMPORTAR:
   • Verificar reporte generado
   • Revisar items en Koha
   • Verificar en OPAC que registros son visibles
   • Guardar logs importantes

✅ MANTENIMIENTO:
   • Limpiar logs antiguos (>30 días)
   • Limpiar archivos procesados (>60 días)
   • Hacer backup de reportes importantes
   • Revisar errores periódicamente

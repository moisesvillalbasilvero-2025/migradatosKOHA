🚀 CÓMO IMPORTAR NUEVAS BIBLIOTECAS
═══════════════════════════════════

Cuando recibas un CSV de cualquiera de estas bibliotecas:


1️⃣  RENOMBRAR el archivo con el código correspondiente:

    Ejemplos:
    • datos_economia.csv      → ECO.csv
    • biblioteca_central.csv  → BC.csv
    • filial_chaco.csv        → AGRC.csv


2️⃣  COLOCAR en la carpeta de importación:

    cp archivo.csv /home/mvillalba/migradatos/importar_aqui/ECO.csv


3️⃣  PROCESAR automáticamente:

    cd /home/mvillalba/migradatos
    ./auto_importar.py

    o directamente:

    ./auto_importar.py ECO.csv


4️⃣  ¡LISTO! El sistema:
    ✓ Detecta el código "ECO"
    ✓ Verifica que existe en Koha
    ✓ Analiza y corrige el CSV
    ✓ Importa a Koha
    ✓ Reindexa
    ✓ Mueve a procesados/

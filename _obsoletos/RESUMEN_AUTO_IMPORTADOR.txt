🎯 CONCEPTO DEL SISTEMA
═══════════════════════

SIMPLE: Colocas CSV → Se analiza → Se importa automáticamente

1. Detecta código de biblioteca del NOMBRE del archivo
2. Verifica que biblioteca existe en Koha
3. Analiza formato CSV
4. Corrige duplicados automáticamente
5. Genera MARCXML
6. Importa a Koha
7. Reindexa
8. Mueve archivo a procesados/ o errores/

🛡️ MANEJO DE ERRORES
═════════════════════

El sistema es robusto y maneja errores automáticamente:

Error                          Acción
─────────────────────────────  ─────────────────────────────────
No detecta código              → Mueve a errores/_SIN_CODIGO
Biblioteca no existe en Koha   → Mueve a errores/_NO_EXISTE
Formato CSV inválido           → Mueve a errores/_FORMATO_INVALIDO
Error generando MARCXML        → Mueve a errores/_ERROR_MARCXML
Error en importación           → Mueve a errores/_ERROR_IMPORT


✅ REQUISITOS
═════════════

1. ✓ Nombre del archivo DEBE contener código de biblioteca

4. ✓ Permisos de ejecución en auto_importar.py

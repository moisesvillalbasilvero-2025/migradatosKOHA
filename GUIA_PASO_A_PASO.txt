  🎯 OBJETIVO
═══════════════════════════════════════════════════════════════════════

Importar un archivo CSV con datos bibliográficos al catálogo Koha OPAC
de forma SEGURA, sin perder trabajo y sin duplicar registros.


═══════════════════════════════════════════════════════════════════════
  📋 ANTES DE EMPEZAR - REQUISITOS
═══════════════════════════════════════════════════════════════════════

1. Tienes un archivo CSV con tus datos bibliográficos
2. Conoces el código de tu biblioteca (ej: MED, VET, ING)
3. Estás conectado por SSH al servidor
4. Estás en el directorio: /home/mvillalba/migradatos

Verificar que estás en el lugar correcto:
  pwd

Debe mostrar: /home/mvillalba/migradatos

Si no estás ahí:
  cd /home/mvillalba/migradatos


═══════════════════════════════════════════════════════════════════════
  📝 PASO 1: PREPARAR TU ARCHIVO CSV
═══════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────┐
│  ¿Qué debe contener tu CSV?                                          │
└──────────────────────────────────────────────────────────────────────┘

COLUMNAS OBLIGATORIAS:
  ✓ titulo        - Título del libro
  ✓ nroacceso     - Código de barras o número de acceso

COLUMNAS RECOMENDADAS:
  • autor         - Autor del libro
  • editorial     - Editorial
  • publicacion   - Año de publicación
  • materia       - Temas o materias
  • isbn          - ISBN del libro
  • ubicacion     - Signatura o cota

FORMATO DEL NOMBRE:
  El archivo debe tener el código de la biblioteca en el nombre:

  ✅ CORRECTO:
     MED.csv
     VET_2025.csv
     ING_octubre.csv
     FACEN_completo.csv

  ❌ INCORRECTO:
     datos.csv
     biblioteca.csv
     libros.csv

┌──────────────────────────────────────────────────────────────────────┐
│  Ejemplo de CSV correcto:                                            │
└──────────────────────────────────────────────────────────────────────┘

  titulo;autor;nroacceso;editorial;publicacion
  Cien años de soledad;García Márquez, Gabriel;MED-001;Sudamericana;1967
  Don Quijote;Cervantes, Miguel de;MED-002;Cátedra;1605
  ...


═══════════════════════════════════════════════════════════════════════
  🔍 PASO 2: VALIDAR EL ARCHIVO
═══════════════════════════════════════════════════════════════════════

Antes de importar, SIEMPRE valida el archivo para detectar problemas.

┌──────────────────────────────────────────────────────────────────────┐
│  COMANDO:                                                            │
└──────────────────────────────────────────────────────────────────────┘

  ./validador_csv.py ruta/a/tu/archivo.csv

┌──────────────────────────────────────────────────────────────────────┐
│  EJEMPLO PRÁCTICO:                                                   │
└──────────────────────────────────────────────────────────────────────┘

  # Si tu archivo está en el escritorio:
  ./validador_csv.py /home/mvillalba/Escritorio/MED.csv

  # Si está en descargas:
  ./validador_csv.py /home/mvillalba/Descargas/VET.csv

  # Si está en la carpeta actual:
  ./validador_csv.py MED.csv

┌──────────────────────────────────────────────────────────────────────┐
│  ¿QUÉ VERÁS?                                                         │
└──────────────────────────────────────────────────────────────────────┘

El validador te mostrará:

  ✓ Tamaño del archivo
  ✓ Encoding detectado (UTF-8, CP1252, etc.)
  ✓ Delimitador usado (;  ,  |)
  ✓ Columnas encontradas
  ✓ Columnas obligatorias presentes
  ✓ Duplicados en códigos de acceso
  ✓ Líneas con problemas

┌──────────────────────────────────────────────────────────────────────┐
│  RESULTADO ESPERADO:                                                 │
└──────────────────────────────────────────────────────────────────────┘

  Si todo está bien:
  ════════════════════════════════════════════════════
  ✓✓✓ ARCHIVO VÁLIDO PARA IMPORTACIÓN ✓✓✓
  ════════════════════════════════════════════════════

  Si hay errores:
  ════════════════════════════════════════════════════
  ✗✗✗ ARCHIVO NO VÁLIDO - CORREGIR ERRORES ✗✗✗
  ════════════════════════════════════════════════════

  → Corrige los errores antes de continuar

┌──────────────────────────────────────────────────────────────────────┐
│  ⚠️  ERRORES COMUNES Y SOLUCIONES:                                   │
└──────────────────────────────────────────────────────────────────────┘

ERROR: "Falta columna obligatoria: titulo"
  → Agregar columna 'titulo' a tu CSV

ERROR: "Falta columna obligatoria: nroacceso"
  → Agregar columna 'nroacceso' con códigos de barras

ADVERTENCIA: "Códigos de acceso duplicados: 50"
  → Revisa tu CSV, algunos códigos se repiten
  → El sistema los corregirá automáticamente


═══════════════════════════════════════════════════════════════════════
  📤 PASO 3: SUBIR EL ARCHIVO
═══════════════════════════════════════════════════════════════════════

Una vez validado, subimos el archivo a la carpeta de importación.

┌──────────────────────────────────────────────────────────────────────┐
│  COMANDO:                                                            │
└──────────────────────────────────────────────────────────────────────┘

  ./subir_csv.sh ruta/a/tu/archivo.csv CODIGO

┌──────────────────────────────────────────────────────────────────────┐
│  EJEMPLOS PRÁCTICOS:                                                 │
└──────────────────────────────────────────────────────────────────────┘

  # Biblioteca de Medicina
  ./subir_csv.sh /home/mvillalba/Escritorio/medicina.csv MED

  # Biblioteca de Veterinaria
  ./subir_csv.sh /home/mvillalba/Descargas/veterinaria.csv VET

  # Biblioteca de Ingeniería
  ./subir_csv.sh datos_ingenieria.csv ING

  # Facultad de Ciencias Exactas
  ./subir_csv.sh facen.csv FACEN

═══════════════════════════════════════════════════════════════════════
  🚀 PASO 4: IMPORTAR CON PERSISTENCIA (¡IMPORTANTE!)
═══════════════════════════════════════════════════════════════════════

Ahora viene la parte más importante: importar CON PERSISTENCIA.

¿Por qué con persistencia?
  • Las importaciones pueden tardar 20-30 minutos
  • Si se corta la conexión SSH, perderías todo el trabajo
  • Con tmux, la importación continúa aunque te desconectes

┌──────────────────────────────────────────────────────────────────────┐
│  COMANDO PRINCIPAL: ⭐⭐⭐                                              │
└──────────────────────────────────────────────────────────────────────┘

  ./importar_con_tmux.sh

┌──────────────────────────────────────────────────────────────────────┐
│  ¿QUÉ PASARÁ?                                                        │
└──────────────────────────────────────────────────────────────────────┘

  1. El script buscará archivos CSV en importar_aqui/

  2. Te mostrará los archivos encontrados:

     Archivos encontrados: 1

       1. MED.csv [MED]

     ¿Procesar estos archivos? (SI/no):

  3. Escribe: SI  (o simplemente presiona Enter)

  4. Te preguntará si quieres continuar aunque ya existan items:

     Items existentes en Koha para MED: 4767
     ⚠ Ya existen 4767 items. Se agregarán NUEVOS registros
     ¿Desea continuar? (SI/no):

  5. Escribe: SI

  6. ¡El proceso empezará dentro de tmux!

┌──────────────────────────────────────────────────────────────────────┐
│  AHORA ESTÁS DENTRO DE TMUX                                          │
└──────────────────────────────────────────────────────────────────────┘

Verás algo como:

  ═══════════════════════════════════════════════════════
  📄 PROCESANDO: MED.csv
  ═══════════════════════════════════════════════════════

  1. DETECCIÓN DE BIBLIOTECA
  ───────────────────────────
  ✓ Código detectado: MED

  2. VERIFICACIÓN EN KOHA
  ───────────────────────
  ✓ Biblioteca: Biblioteca de Medicina

  3. ANÁLISIS DEL CSV
  ──────────────────
  ✓ Total de registros: 4850
  ✓ Columnas detectadas: 15

  4. VERIFICACIÓN DE ITEMS EXISTENTES
  ──────────────────────────────────
  Items actuales en Koha para MED: 4767

  5. GENERACIÓN DE MARCXML
  ────────────────────────
  → Generando MARCXML...

  ... (el proceso continúa)


═══════════════════════════════════════════════════════════════════════
  ⌨️  PASO 5: DESCONECTARSE SIN DETENER (¡CLAVE!)
═══════════════════════════════════════════════════════════════════════

Aquí está la MAGIA de tmux:

Puedes desconectarte de la sesión y la importación SEGUIRÁ CORRIENDO.

┌──────────────────────────────────────────────────────────────────────┐
│  PARA DESCONECTARTE:                                                 │
└──────────────────────────────────────────────────────────────────────┘

  1. Presiona: Ctrl + b
  2. Suelta ambas teclas
  3. Presiona: d

¡Eso es todo! Verás:

  [detached (from session importacion-koha)]

┌──────────────────────────────────────────────────────────────────────┐
│  AHORA PUEDES:                                                       │
└──────────────────────────────────────────────────────────────────────┘

  ✓ Cerrar la terminal SSH
  ✓ Apagar tu computadora
  ✓ Irte a casa
  ✓ Hacer otras cosas

  La importación SIGUE CORRIENDO en el servidor ⭐

═══════════════════════════════════════════════════════════════════════
  ⚠️  PROBLEMAS COMUNES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────┐
│  PROBLEMA 1: "No se detectó código de biblioteca"                   │
└──────────────────────────────────────────────────────────────────────┘

CAUSA: El nombre del archivo no contiene el código

SOLUCIÓN:
  Renombra el archivo:
    mv datos.csv MED.csv

  O especifica el código al subir:
    ./subir_csv.sh datos.csv MED

┌──────────────────────────────────────────────────────────────────────┐
│  PROBLEMA 2: "La biblioteca 'XXX' NO existe en Koha"                │
└──────────────────────────────────────────────────────────────────────┘

CAUSA: El código de biblioteca no está registrado en Koha

SOLUCIÓN:
  1. Verificar código correcto en Koha
  2. O crear la biblioteca en:
     Staff Interface → Administración → Bibliotecas

┌──────────────────────────────────────────────────────────────────────┐
│  PROBLEMA 3: "Me desconecté y no sé si sigue corriendo"             │
└──────────────────────────────────────────────────────────────────────┘

SOLUCIÓN:
  1. Verificar sesiones tmux:
     tmux ls

  2. Ver procesos activos:
     ./monitor_importacion.sh

  3. Reconectar:
     ./importar_con_tmux.sh --attach

┌──────────────────────────────────────────────────────────────────────┐
│  PROBLEMA 4: "Quiero detener la importación"                        │
└──────────────────────────────────────────────────────────────────────┘

SOLUCIÓN:
  1. Conectar a la sesión:
     ./importar_con_tmux.sh --attach

  2. Presionar: Ctrl + C

  3. O matar la sesión:
     ./importar_con_tmux.sh --kill

┌──────────────────────────────────────────────────────────────────────┐
│  PROBLEMA 5: "¿Se importaron duplicados?"                           │
└──────────────────────────────────────────────────────────────────────┘

SOLUCIÓN:
  Verificar:
    ./verificar_duplicados.sh --biblioteca MED

  Si hay duplicados (no debería):
    ./verificar_duplicados.sh --auto-fix

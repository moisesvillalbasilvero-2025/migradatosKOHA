═══════════════════════════════════════════════════════════════════════
  🛠️ SOLUCIÓN RÁPIDA DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

PROBLEMA: "No se detectó código de biblioteca"
  → Renombrar archivo: datos.csv → MED.csv

PROBLEMA: "La biblioteca no existe en Koha"
  → Ver bibliotecas: sudo koha-mysql koha-cnc -e "SELECT * FROM branches"
  → Crear en Staff Interface → Administración → Bibliotecas

PROBLEMA: "Faltan columnas obligatorias"
  → Verificar CSV tiene: titulo, nroacceso
  → Validar: ./validador_csv.py archivo.csv

PROBLEMA: "Duplicados en códigos de acceso"
  → Ver duplicados: awk -F';' '{print $2}' archivo.csv | sort | uniq -d
  → Corregir manualmente o usar script de corrección

PROBLEMA: "Error de memoria"
  → Dividir archivo en partes más pequeñas
  → split -l 5000 archivo.csv parte_

PROBLEMA: "Timeout en reindexación"
  → No crítico, reindexar después:
    sudo koha-rebuild-zebra -v koha-cnc

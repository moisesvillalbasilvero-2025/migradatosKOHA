┌─────────────────────────────────────────────────────────────────────────┐
│ 📚 CAPÍTULO 1: ¿QUÉ ES UN LIBRO EN KOHA?                               │
└─────────────────────────────────────────────────────────────────────────┘

Un libro en Koha tiene 3 partes:

    ┌──────────────────────────────────────────────────────────┐
    │  1️⃣  BIBLIO (El LIBRO en sí)                            │
    │     ├─ Título: "Cien años de soledad"                   │
    │     ├─ Autor: "García Márquez, Gabriel"                 │
    │     └─ Resumen: "Historia de los Buendía..."            │
    └──────────────────────────────────────────────────────────┘
                              ▼
    ┌──────────────────────────────────────────────────────────┐
    │  2️⃣  BIBLIOITEM (La EDICIÓN específica)                │
    │     ├─ ISBN: 978-84-376-0494-7                          │
    │     ├─ Editorial: "Sudamericana"                        │
    │     ├─ Año: 1967                                        │
    │     └─ Páginas: 471                                     │
    └──────────────────────────────────────────────────────────┘
                              ▼
    ┌──────────────────────────────────────────────────────────┐
    │  3️⃣  ITEM (El EJEMPLAR físico)                         │
    │     ├─ Código de barras: LIBRO001                       │
    │     ├─ Biblioteca: ING (Ingeniería)                     │
    │     ├─ Ubicación: Estantería General                    │
    │     └─ Signatura: 863 GAR                               │
    └──────────────────────────────────────────────────────────┘

💡 ANALOGÍA:
   BIBLIO     = La obra "Don Quijote"
   BIBLIOITEM = Edición de Planeta, 2005
   ITEM       = La copia física con código LIBRO002


┌─────────────────────────────────────────────────────────────────────────┐
│ 📝 CAPÍTULO 2: EL ARCHIVO CSV - TU LISTA DE LIBROS                     │
└─────────────────────────────────────────────────────────────────────────┘

El CSV es como una TABLA de Excel:

    ┌────────┬───────┬──────┬───────┬─────────┐
    │ Título │ Autor │ ISBN │ Tipo  │ Código  │  ← ENCABEZADO
    ├────────┼───────┼──────┼───────┼─────────┤
    │ Libro1 │ Autor1│ 123..│  BK   │ LIB001  │  ← LIBRO 1
    ├────────┼───────┼──────┼───────┼─────────┤
    │ Libro2 │ Autor2│ 456..│  BK   │ LIB002  │  ← LIBRO 2
    ├────────┼───────┼──────┼───────┼─────────┤
    │ Libro3 │ Autor3│ 789..│  BK   │ LIB003  │  ← LIBRO 3
    └────────┴───────┴──────┴───────┴─────────┘

Cada FILA = Un libro completo
Cada COLUMNA = Un dato del libro


┌─────────────────────────────────────────────────────────────────────────┐
│ 🎯 CAPÍTULO 3: CAMPOS OBLIGATORIOS (Los que NO pueden faltar)          │
└─────────────────────────────────────────────────────────────────────────┘

    ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
    ┃  🔴 CRÍTICO - Sin esto NO funciona                     ┃
    ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

    ✅ title         →  Título del libro
                        Ejemplo: "Don Quijote"

    ✅ barcode       →  Código ÚNICO del ejemplar
                        Ejemplo: "LIBRO001"

    ✅ homebranch    →  ¿En qué biblioteca está?
                        Ejemplo: "ING" o "ODO" o "QUI"

    ✅ itemtype      →  ¿Qué tipo de material es?
                        Ejemplo: "BK" (libro)


    ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
    ┃  🟡 IMPORTANTE - Para que se vea bien en OPAC          ┃
    ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

    ⭐ author         →  Nombre del autor
                        Ejemplo: "Cervantes, Miguel de"

    ⭐ isbn           →  Código internacional del libro
                        Ejemplo: "978-84-376-0494-7"

    ⭐ abstract       →  Resumen del contenido
                        Ejemplo: "Las aventuras de un hidalgo..."

    ⭐ subject        →  De qué trata (materia)
                        Ejemplo: "Literatura española"


┌─────────────────────────────────────────────────────────────────────────┐
│ 🎨 CAPÍTULO 4: CÓDIGOS COMUNES (Valores que puedes usar)               │
└─────────────────────────────────────────────────────────────────────────┘

╔═══════════════════════════════════════════════════════════════════════╗
║  ITEMTYPE - ¿Qué tipo de material es?                                ║
╚═══════════════════════════════════════════════════════════════════════╝

    📕 BK     = Libro (Book)
    💿 DVD    = DVD/Video
    🎵 CD     = CD de audio
    📰 MAG    = Revista (Magazine)
    📄 NEWS   = Periódico
    🗺️  MAP    = Mapa
    🎼 SCORE  = Partitura musical

╔═══════════════════════════════════════════════════════════════════════╗
║  HOMEBRANCH - ¿En qué biblioteca está?                               ║
╚═══════════════════════════════════════════════════════════════════════╝

    🏛️  ING = Facultad de Ingeniería
    🦷 ODO = Facultad de Odontología
    ⚗️  QUI = Facultad de Química
    🏛️  ARQ = Facultad de Arquitectura
    ⚖️  DER = Facultad de Derecho

╔═══════════════════════════════════════════════════════════════════════╗
║  CCODE - Colección (tipo de contenido)                               ║
╚═══════════════════════════════════════════════════════════════════════╝

    📖 FIC    = Ficción (novelas)
    📚 NF     = No ficción (ensayos, biografías)
    📔 TEXTB  = Libro de texto
    🎓 TESIS  = Tesis de grado
    👶 INF    = Infantil
    🧒 JUV    = Juvenil

╔═══════════════════════════════════════════════════════════════════════╗
║  TIP 1: Formato de Autor                                             ║
╚═══════════════════════════════════════════════════════════════════════╝

    ❌ MAL:   "Gabriel García Márquez"
    ✅ BIEN:  "García Márquez, Gabriel"

    Siempre: APELLIDO, Nombre


╔═══════════════════════════════════════════════════════════════════════╗
║  TIP 2: Códigos de Barras                                            ║
╚═══════════════════════════════════════════════════════════════════════╝

    ❌ MAL:   Repetir el mismo código
    ✅ BIEN:  Cada libro tiene código ÚNICO

    Ejemplos:
    - LIBRO001, LIBRO002, LIBRO003...
    - ING001, ING002, ING003...
    - 2025-ING-001, 2025-ING-002...


╔═══════════════════════════════════════════════════════════════════════╗
║  TIP 3: Campos con Comas                                             ║
╚═══════════════════════════════════════════════════════════════════════╝

    Si un campo tiene comas, usar comillas:

    ❌ MAL:   Historia, crónica y novela
    ✅ BIEN:  "Historia, crónica y novela"


╔═══════════════════════════════════════════════════════════════════════╗
║  TIP 4: Resúmenes Atractivos                                         ║
╚═══════════════════════════════════════════════════════════════════════╝

    ❌ MAL:   "Libro sobre historia"
    ✅ BIEN:  "Fascinante recorrido por los eventos más
               importantes del siglo XX, narrado con maestría
               y respaldado por investigación exhaustiva."

    Un buen resumen = Más usuarios interesados


┌─────────────────────────────────────────────────────────────────────────┐
│ 🎓 CAPÍTULO 8: ERRORES COMUNES Y CÓMO EVITARLOS                        │
└─────────────────────────────────────────────────────────────────────────┘

┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  ERROR 1: "Código de barras duplicado"                               ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Causa:    Usaste el mismo barcode dos veces
Solución: Cada libro DEBE tener código único

    Buscar duplicados en tu CSV:
    cut -d',' -f11 archivo.csv | sort | uniq -d


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  ERROR 2: "Biblioteca no existe"                                     ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Causa:    Pusiste un código de biblioteca inválido
Solución: Usa solo códigos que existan en Koha

    Ver bibliotecas válidas:
    koha-mysql koha-cnc -e "SELECT branchcode FROM branches"


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  ERROR 3: "CSV malformado"                                           ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Causa:    Faltan columnas o hay líneas vacías
Solución: Validar con el script antes de importar

    ./validar_antes_importar.sh tu_archivo.csv

    ⭐⭐⭐ NIVEL 3: COMPLETO (Avanzado)
    ────────────────────────────────────
    + abstract, subject, dewey
    Resultado: Experiencia profesional

    ⭐⭐⭐⭐ NIVEL 4: PREMIUM (Experto)
    ────────────────────────────────────
    + portadas, tabla contenidos, URLs
    Resultado: Comparable a Amazon

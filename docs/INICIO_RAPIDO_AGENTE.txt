🚀 INICIO RÁPIDO - 3 PASOS
══════════════════════════════════════════════════════════════════════

1️⃣  PREPARAR TU CSV

    El nombre debe contener el código de biblioteca:

    ✅ Correcto:
       MED.csv
       VET_2025.csv
       ING_octubre.csv
       FACAGR_completo.csv

    ❌ Incorrecto:
       datos.csv
       biblioteca.csv


2️⃣  COLOCAR EN CARPETA DE IMPORTACIÓN

    cp tu_archivo.csv /home/mvillalba/migradatos/importar_aqui/


3️⃣  EJECUTAR IMPORTADOR

    cd /home/mvillalba/migradatos
    ./importar_automatico.sh

    ¡Listo! El sistema procesa automáticamente.


═══════════════════════════════════════════════════════════════════════
OPCIONES DE USO
═══════════════════════════════════════════════════════════════════════

📌 PROCESAR UN ARCHIVO DIRECTAMENTE

   ./agente_importador_v2.py /ruta/al/archivo.csv

   Ejemplo:
   ./agente_importador_v2.py importar_aqui/MED.csv


📌 PROCESAR MÚLTIPLES ARCHIVOS

   ./agente_importador_v2.py archivo1.csv archivo2.csv archivo3.csv

   Ejemplo:
   ./agente_importador_v2.py importar_aqui/*.csv


📌 BUSCAR Y PROCESAR AUTOMÁTICAMENTE

   ./importar_automatico.sh

   - Busca todos los CSV en importar_aqui/
   - Detecta código de biblioteca automáticamente
   - Procesa cada uno secuencialmente


📌 PROCESAR SOLO UNA BIBLIOTECA

   ./importar_automatico.sh --biblioteca MED

   Solo procesa archivos de la biblioteca MED


📌 BUSCAR EN DIRECTORIO ESPECÍFICO

   ./importar_automatico.sh --dir /ruta/personalizada


📌 MODO VIGILANCIA (AUTOMÁTICO CONTINUO)

   ./importar_automatico.sh --watch

   - Monitorea carpeta importar_aqui/
   - Procesa automáticamente archivos nuevos
   - Queda corriendo hasta que presiones Ctrl+C

═══════════════════════════════════════════════════════════════════════
CONTROL DE DUPLICADOS
═══════════════════════════════════════════════════════════════════════

El sistema verifica duplicados en DOS niveles:

1. DENTRO DEL CSV
   - Detecta códigos de acceso repetidos
   - Corrige automáticamente si > 50 duplicados

2. EN BASE DE DATOS KOHA
   - Consulta items existentes para la biblioteca
   - Informa cantidad y solicita confirmación
   - NO duplica registros al importar


═══════════════════════════════════════════════════════════════════════
REQUISITOS DEL CSV
═══════════════════════════════════════════════════════════════════════

Campos OBLIGATORIOS:
  • titulo
  • nroacceso

Campos opcionales:
  • autor
  • editorial
  • anio
  • isbn
  • materia
  • notas
  • etc.

Formato:
  • Separador: , (coma) o ; (punto y coma)
  • Codificación: UTF-8
  • Primera fila: nombres de columnas

EJEMPLO COMPLETO

# Situación: Importar registros de Facultad de Medicina

# Paso 1: Preparar CSV
cp /datos_origen/medicina_2025.csv importar_aqui/MED.csv

cd /home/mvillalba/migradatos
./importar_automatico.sh

# El sistema preguntará:
# ¿Procesar estos archivos? (SI/no): SI

# Si ya existen items:
# ¿Desea continuar de todas formas? (escriba SI): SI

# Paso 4: Verificar
./importar_automatico.sh --stats

WORKFLOW RECOMENDADO
═══════════════════════════════════════════════════════════════════════

OPCIÓN A: Manual (Cuando tengas archivos listos)
─────────────────────────────────────────────────

1. Colocar CSV en importar_aqui/ con nombre correcto
2. Ejecutar: ./importar_automatico.sh
3. Revisar logs en: logs/


OPCIÓN B: Automático (Procesamiento continuo)
──────────────────────────────────────────────

1. Iniciar vigilancia:
   nohup ./importar_automatico.sh --watch > vigilancia.log 2>&1 &

2. Colocar archivos cuando estén listos en importar_aqui/

3. Se procesan automáticamente

4. Ver progreso:
   tail -f vigilancia.log


═══════════════════════════════════════════════════════════════════════
SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

❌ "No se detectó código de biblioteca"
   → Renombrar: mv datos.csv MED_datos.csv

❌ "La biblioteca 'XYZ' NO existe en Koha"
   → Crear en: Staff → Administración → Bibliotecas

❌ "Faltan campos: titulo, nroacceso"
   → Verificar CSV tiene esos campos

❌ "Error de permisos"
   → Verificar permisos: chmod +x agente_importador_v2.py

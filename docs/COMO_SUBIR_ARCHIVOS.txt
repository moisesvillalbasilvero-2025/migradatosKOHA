Los permisos ya están configurados. Ahora puedes subir archivos de 3 formas:


═══════════════════════════════════════════════════════════════════════
OPCIÓN 1: SCRIPT AUTOMÁTICO (Recomendado)
═══════════════════════════════════════════════════════════════════════

Usar el script helper que hace todo por ti:

    ./subir_csv.sh archivo.csv CODIGO

Ejemplos:

    # Subir archivo y renombrar a MED.csv
    ./subir_csv.sh medicina_2025.csv MED

    # Subir archivo desde otra ubicación
    ./subir_csv.sh /tmp/datos.csv VET

    # Subir con nombre original (debe tener código en el nombre)
    ./subir_csv.sh QUI_octubre.csv


═══════════════════════════════════════════════════════════════════════
OPCIÓN 2: COPIAR MANUALMENTE
═══════════════════════════════════════════════════════════════════════

Copiar directamente a la carpeta de importación:

    cp tu_archivo.csv /home/mvillalba/migradatos/importar_aqui/CODIGO.csv

Ejemplos:

    cp medicina.csv /home/mvillalba/migradatos/importar_aqui/MED.csv
    cp veterinaria.csv /home/mvillalba/migradatos/importar_aqui/VET.csv
    cp quimica.csv /home/mvillalba/migradatos/importar_aqui/QUI.csv


═══════════════════════════════════════════════════════════════════════
OPCIÓN 3: DESDE OTRO SERVIDOR (SCP/SFTP)
═══════════════════════════════════════════════════════════════════════

Si estás en otra máquina, puedes usar SCP:

    scp archivo.csv mvillalba@servidor:/home/mvillalba/migradatos/importar_aqui/CODIGO.csv

Ejemplo:

    scp medicina.csv mvillalba@192.168.1.100:/home/mvillalba/migradatos/importar_aqui/MED.csv

═══════════════════════════════════════════════════════════════════════
DESPUÉS DE SUBIR
═══════════════════════════════════════════════════════════════════════

Una vez que el archivo está en importar_aqui/, tienes 3 opciones:


🔹 OPCIÓN A: Procesar automáticamente todos los archivos

    cd /home/mvillalba/migradatos
    ./importar_automatico.sh


🔹 OPCIÓN B: Procesar un archivo específico

    ./agente_importador_v2.py importar_aqui/CODIGO.csv


🔹 OPCIÓN C: Modo vigilancia (automático continuo)

    ./importar_automatico.sh --watch

    Luego solo sube archivos y se procesan solos cada 10 segundos.

═══════════════════════════════════════════════════════════════════════
SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

❌ "Permission denied"
   → Verificar permisos:
     ls -ld importar_aqui/

   → Si no tienes permisos:
     sudo chown mvillalba:mvillalba importar_aqui/
     sudo chmod 775 importar_aqui/


❌ "No such file or directory"
   → Verificar que la ruta es correcta:
     pwd
     ls -la

   → Crear carpeta si no existe:
     mkdir -p /home/mvillalba/migradatos/importar_aqui


❌ Archivo no se procesa
   → Verificar nombre tiene código de biblioteca:
     ls importar_aqui/

   → Renombrar si es necesario:
     mv importar_aqui/datos.csv importar_aqui/MED.csv
